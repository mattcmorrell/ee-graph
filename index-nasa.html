Contributing

Everything here is built on a shared graph dataset — 783 nodes, 3,281 edges across 30 types. Build whatever you want on top of it.

1
Get the data

The graph lives in data/nodes.json and data/edges.json. Schema is in data/schema.json. Clone the repo or just grab the files.

2
Build something

Any format works — a prototype, a notebook, a Figma file, a script, a video. If it uses the graph data and shows something interesting, it belongs here.

3
Share it

Push to a poc/ branch, drop a link in Slack, or just show someone. We'll add it to this page.
