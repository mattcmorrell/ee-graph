How this works
How do I add an experiment?
Open this project in Claude Code and say something like add an experiment called "My Thing" with a link to myurl.com. Claude will add a card to this page and push it live.
How do I update text or content on this page?
Just tell Claude. Change the description on the Google card to "..." or mark Interview Intelligence as Updated. It edits the HTML directly.
Can I add a video?
Yes. Give Claude a Wistia or other video link when adding an experiment and it will include it on the card.
Can I add to the graph dataset?
Yes. Tell Claude what you want to add — new node types, new edges, new properties. It can read the schema in data/schema.json and extend the graph while keeping everything consistent. Just describe what you need and it will figure out how to wire it in.
Do I need to know git?
No. Claude handles commits and pushes. You just describe what you want.

Build on the graph

Every experiment on this page uses the same employee graph — a dataset of people, teams, projects, and how they're all connected. You can use it too.

1
Open the project

Open the ee-graph project in Claude Code. The employee data is in the data/ folder — Claude can read it and use it in whatever you build.

2
Make something

Tell Claude what you want to explore. A prototype, a visualization, a workflow, a Figma file — anything goes. The interesting part is what happens when you follow the connections in the data.

3
Add it here

When you're ready, ask Claude to add your experiment to this gallery page. It can create a card, link your work, and push the changes — no git knowledge needed.
