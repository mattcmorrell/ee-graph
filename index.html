Build on the graph

Every experiment on this page uses the same employee graph — a dataset of people, teams, projects, and how they're all connected. You can use it too.

1
Open the project

Open the ee-graph project in Claude Code. The employee data is in the data/ folder — Claude can read it and use it in whatever you build.

2
Make something

Tell Claude what you want to explore. A prototype, a visualization, a workflow, a Figma file — anything goes. The interesting part is what happens when you follow the connections in the data.

3
Add it here

When you're ready, ask Claude to add your experiment to this gallery page. It can create a card, link your work, and push the changes — no git knowledge needed.
